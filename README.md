# Hoysii Codex Context Pack

Copy this folder into the Hoysii repository.

Recommended placement:

```text
hoysii/
├── AGENTS.md
├── docs/
│   ├── PRODUCT.md
│   ├── CUSTOMER_JOURNEY.md
│   ├── OPERATIONS.md
│   └── SEO_STRATEGY.md
└── ...
```

`AGENTS.md` gives Codex concise project context. The `docs/` files contain the deeper product, journey, operations, and SEO decisions.

Cloudflare API, D1, R2, Better Auth, and migration setup: [worker/README.md](worker/README.md).
